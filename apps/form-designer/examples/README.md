# 条件分支演示流程

这些是用户要求增加的本地演示定义，名称统一带“【示例】”。每个流程有独立表单、默认填写内容及已发布版本，不预先创建审批申请或处理记录。

入口：审批首页 → 发起审批 → 对应分类 → 示例卡片。管理员也可从“更多”搜索示例名，点击“编辑流程表单”，再切到“流程设计”查看条件及处理人。

| 分类 | 示例 | 调整哪些值 | 对应路径 |
| --- | --- | --- | --- |
| 采购流程 | 设备采购申请 | 采购金额10000 / 10001 | 超过10000元增加管理员复核，最后采购执行 |
| 财务流程 | 费用报销申请 | 报销金额3000 / 3001 | 超过3000元增加管理员复核，最后财务登记 |
| 人事流程 | 员工请假申请 | 请假天数2 / 3 | 3天及以上增加管理员复核 |
| 行政流程 | 行政用印申请 | 普通证明 / 合同用印 | 合同用印增加管理员复核，最后用印办理 |
| 销售流程 | 销售合同审批 | 合同金额9999 / 10000 / 50000；非标准条款否 / 是 | 金额按小额／常规／大额三路分流，汇合后再按条款判断是否风险复核，最后合同归档 |

销售合同采用两段串联条件，当前设计器可完整查看和编辑。金额判断按出口顺序优先匹配：先判断不低于50000元，再判断不低于10000元，最后走不足10000元的默认出口；非标准条款独立判断。所有条件均保留一个默认出口。

演示步骤：

1. 使用已获准的普通账号（如employee-a）打开示例，修改表中金额、天数或类型并提交。
2. 申请提交后，在申请详情查看实际审批路径；不同条件只生成命中分支的任务。
3. 主管审批使用approver；管理员复核／金额复核／风险复核使用admin。登录对应账号，从“待我处理”处理。
4. 采购执行、用印办理和合同归档使用employee-a；财务登记和商务核验使用employee-b。前序审批完成后，执行人才会收到可处理任务。
5. 可以从“我发起的”查看记录或撤回处理中申请。审批及执行字段设为只读，发起人填写字段可编辑。

这些流程使用指定演示人员，不依赖分类主管，也不改动现有分类主管配置。若自行把审批节点改为“直属主管”，仍需先配置对应分类主管才能发布、提交。

`branch-demos.json`保存5组表单／流程定义和15组分支样例（含阈值边界），便于本地复现。辅助目录`form-designer-integration`中的`seed_branch_demos.py --apply`通过本地公开API安装并发布，已有同ID表单或流程会跳过，避免覆盖后续编辑；不带`--apply`仅查看计划。`verify_branch_demos.py --installed`进行规则校验及只读运行时预览，不创建申请。该数据文件不会被生产应用自动导入。
