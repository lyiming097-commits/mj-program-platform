# 页面设计风格规范

统一入口见 [全平台规范 skill](../skills/mj-platform-standards/SKILL.md)。本文保留详细背景；新模板的参数与明确例外以 skill 为准。

本文档用于约束门户、Auth 设置页、CRM、线缆商城以及后续 ERP/产品档案等系统的页面风格。目标是：用户在不同系统间切换时，顶部栏、左侧栏、账号菜单、基础控件和信息密度保持一致，只让业务内容区体现模块差异。

## 1. 总原则

1. 所有内部业务系统都是工作台，不做营销页、落地页、大横幅、装饰插画、渐变背景球。
2. 页面应安静、紧凑、可扫描，优先服务重复操作、查询、筛选、录入、审批和管理。
3. 顶部栏和左侧栏是全平台统一框架，必须一模一样；业务模块不得自行改高度、宽度、颜色、头像菜单和返回入口。
4. 内容区可以按业务复杂度设计，但必须使用统一色板、圆角、字号、按钮、表格、弹窗和抽屉规则。
5. 图标统一使用 `@lucide/vue`，不要手写 SVG 图标；按钮里有合适图标时必须放图标。

## 2. 必须统一的外层框架

### 2.1 桌面端顶部栏

顶部栏是所有系统第一层容器，必须视觉一致。

硬性尺寸：

```text
高度：56px，Tailwind 用 h-14
宽度：100vw
位置：固定在顶部，或在 h-screen flex-col 壳内作为第一行，但视觉上必须占满顶部
背景：#ffffff
下边框：1px solid #e2e8f0 / border-slate-200
z-index：高于左侧栏和内容区
左右 padding：16px
```

左侧品牌：

```text
显示文字：迈杰教育科技
字号：18px 或 text-lg
字重：700
颜色：#0f172a / text-slate-950
单行 truncate
```

右侧用户入口：

```text
布局：姓名 + userId + 头像
姓名字号：14px，font-medium
userId 字号：12px，颜色 #1e3a8a 70% 或 #64748b
头像：40x40，圆角正方形，统一 rounded-2xl / 16px
头像失败或无头像：显示姓名首字，背景浅蓝，文字蓝色
hover：浅灰背景 #f8fafc
```

代理状态必须显示：

```text
当前用户显示为被代理人
下拉菜单中显示“由 <actorDisplay> 代理”
必须提供“退出代理”按钮
```

### 2.2 桌面端左侧栏

左侧栏从顶部栏下方开始，所有系统必须一致。

硬性尺寸：

```text
宽度：216px，Tailwind 用 w-[216px]
顶部位置：top: 56px 或在顶部栏下方的 flex 行内
高度：calc(100vh - 56px)
背景：#ffffff
右边框：1px solid #e2e8f0 / border-slate-200
桌面端显示：md:flex
移动端隐藏：hidden
```

左侧栏头部：

```text
高度：64px，建议 h-16
padding：16px
底边框：border-slate-100
图标容器：36x36，rounded-lg，主色背景，白色图标
模块名：14px，font-semibold/bold，text-slate-900/950，truncate
副标题：12px，text-blue-900/60 或 text-slate-500，可选
```

左侧导航项：

```text
高度：40px，Tailwind 用 h-10
圆角：8px，rounded-lg
左右 padding：12px
图标：16px，shrink-0
文字：14px，font-medium 或 font-semibold
间距：gap-3
```

导航状态：

```text
默认：text-slate-600/700
hover：bg-slate-50，text-slate-900 或 text-sky-700
active：bg-sky-50 或 bg-blue-50，text-sky-700/blue-700
禁止：disabled 时不可 hover 变色，不可移动
```

左侧栏底部：

```text
固定在底部
padding：12px
顶部边框：border-slate-100
返回按钮高度：40px
文案统一：返回上一级
```

### 2.3 顶部栏和左侧栏的实现要求

1. 后续新增系统必须复用同一套组件，不允许再复制后改样式。
2. 当前已抽出公共源码包，路径为 `packages/platform-ui/src`。各系统仍然独立 Docker 构建，但构建时会把这份源码复制进镜像并打包到自己的前端产物中。
3. 公共组件：

```text
PlatformTopBar.vue：统一顶部栏、头像菜单、组织架构入口、离职交接入口、退出代理、退出登录
PlatformSidebar.vue：统一左侧栏外观、模块头、导航项、分组导航、底部返回按钮
```

4. 各系统通过 `@platform-ui` 引入公共组件，不直接改框架组件样式。
5. 顶部栏必须使用同一个 `PlatformTopBar`；门户、Auth 设置页、CRM、线材商城已经接入。
6. 左侧栏必须使用同一个 `PlatformSidebar`；门户、Auth 桌面设置页、CRM、线材商城已经接入，点击后的业务行为由父页面决定：

```text
门户：首页侧边栏点击系统路径，使用 window.location.assign 跳转到 CRM/线材商城等独立系统
CRM：侧边栏点击 navGroups，调用 selectGroup，只切换 CRM 内部页面
线材商城：侧边栏点击 grouped tabs，调用 switchActiveTab，只切换线材商城内部页签
```

7. 头像菜单里的组织架构、离职交接、退出代理、退出登录顺序必须一致。

构建要求：

```text
Vite alias：@platform-ui -> packages/platform-ui/src，本地开发使用仓库路径，Docker 内使用 /platform-ui/src
Dockerfile：每个前端镜像必须 COPY packages/platform-ui /platform-ui
公共组件依赖：使用各 app 自己安装的 vue 和 @lucide/vue
```

推荐菜单顺序：

```text
用户信息卡
组织架构
离职交接（仅 full access）
退出代理（仅代理中）
退出登录（非钉钉环境）
```

## 3. 页面背景和布局

外层背景：

```text
门户首页：#eef3f9
业务模块工作区：#f1f5f9 或 bg-slate-100
页面文字主色：#0f172a / text-slate-950
```

主内容区：

```text
桌面端左侧留出 216px
内容区域 min-width: 0
复杂表格页面使用 overflow-hidden，内部表格自己滚动
普通管理页使用 overflow-y-auto
内容 padding：12px-16px，Tailwind 用 p-3 sm:p-4
```

内容页标题：

```text
页面主标题：24px / text-2xl，仅用于门户首页或一级页面
模块内标题：16px-18px，不使用 hero 大标题
辅助说明：12px-14px，颜色 #64748b 或 #1e3a8a 65%
```

基础色：

```text
page bg：#eef3f9 / #f1f5f9
surface：#ffffff
surface soft：#f8fafc
border：#e2e8f0 / #dbe3ee
text main：#0f172a
text body：#334155 / #475569
text muted：#64748b / #94a3b8
```

主色：

```text
primary：#2563eb 或 Tailwind blue-600
primary hover：#1d4ed8
primary soft：#eff6ff / #dbeafe
active nav：#eaf3ff 或 #eff6ff
```

语义色：

```text
success：#047857，背景 #f0fdf4，边框 #bbf7d0
warning：#b45309/#d97706，背景 #fff7ed
danger：#dc2626/#be123c，背景 #fef2f2/#fff1f2
info：#0369a1，背景 #f0f9ff
```

禁止事项：

```text
不要大面积紫色、棕色、橙色、深蓝渐变
不要使用装饰性渐变球、光斑、背景图
不要每个模块自定义一套主色
```

## 5. 圆角、阴影和边框

圆角：

```text
常规按钮/输入框/导航项：8px，rounded-lg
小标签/状态：4px-6px
大型弹窗：10px-12px
卡片最大建议：8px，除弹窗外不要大圆角
```

阴影：

```text
普通卡片：shadow-sm 或 0 1px 2px rgba(15, 23, 42, 0.04)
hover 卡片：轻微 shadow-md，不要强烈浮起
下拉菜单：0 18px 40px rgba(15, 23, 42, 0.16)
抽屉/弹窗：0 22px 52px rgba(15, 23, 42, 0.22)
```

边框：

```text
默认边框：1px solid #e2e8f0
表格边框：#e5edf6
强调边框：#93c5fd / #60a5fa
```

## 6. 按钮规范

基础按钮：

```text
高度：34px-40px
圆角：6px-8px
padding：水平 12px-16px
字号：13px-14px
字重：600-700
图标：16px
```

按钮类型：

```text
主按钮：蓝底白字，用于提交、保存、确认
次按钮：白底灰边，用于取消、返回、普通操作
危险按钮：红色，仅用于删除、停用、退出登录
警告按钮：橙色，仅用于退出代理、放弃修改等可恢复但需确认的动作
```

交互：

```text
hover 不改变布局尺寸
loading 状态显示“处理中...”或具体动作，例如“退出中...”
disabled 必须降低透明度并禁止点击
```

## 7. 表单和筛选

输入框：

```text
高度：34px-40px
圆角：8px
边框：#cbd5e1
背景：#ffffff
focus：蓝色边框 + 2px 蓝色弱阴影
placeholder：#94a3b8
```

筛选区：

```text
复杂列表使用顶部工具条
工具条背景白色或 #f8fafc
筛选按钮高度 30px-34px
筛选菜单圆角 8px-10px
筛选状态 active 用浅蓝底
```

不要把筛选项做成大卡片堆叠；CRM 这类数据密集页面优先横向工具条、下拉筛选、表头筛选。

## 8. 表格和列表

表格页面是 CRM 和线缆商城的主要形态，应保持高密度但清晰。

表格：

```text
表头背景：#f8fafc 到 #eef3f8 的浅渐变，或纯 #f8fafc
表头字号：13px，font-weight 800
行高：40px-48px
单元格边框：#e5edf6
奇偶行：偶数行可用 #fbfdff
hover 行：#eff6ff
sticky 单元格 hover：#eaf3ff
```

列表横向滚动：

```text
所有桌面端宽表格、宽列表页面必须支持按住表体后左右拖拽横向滑动。
宽表横向滚动条默认隐藏，主要通过按住拖拽或触控板横滑完成左右浏览。
拖拽只作用于表格/列表滚动容器，不影响按钮、输入框、下拉浮层、链接、可编辑内容。
拖拽过程中使用抓取态光标；发生有效横向拖拽后，必须拦截随后一次误点击，避免打开详情或触发操作。
移动端仍优先使用原生横向滑动，不额外改变纵向滚动体验。
```

列表卡片：

```text
只用于门户模块入口、移动端列表、重复实体卡片
不要用卡片套卡片
不要把整个页面 section 做成悬浮大卡片
卡片内标题 14px-16px，辅助信息 12px-14px
```

空状态：

```text
白色面板
小图标 48x48
标题 16px
说明 14px muted
主操作按钮在下方
```

## 9. Tabs 和二级导航

左侧栏用于一级模块导航。

内容区顶部 tabs 用于当前模块内的二级切换：

```text
高度：32px
圆角：6px
active：深色底白字，或浅蓝底蓝字，但同一模块内保持一致
默认：bg-slate-100 text-slate-600
hover：bg-slate-200
```

线缆商城存在分组侧栏：

```text
分组标题：34px，高亮浅蓝背景
分组项：40px
active：浅蓝底 + 左侧 3px 蓝色强调线
```

CRM 当前用一级左侧栏 + 顶部二级 tabs；线缆商城当前用分组左侧栏。后续如果新增模块，优先按 CRM 模式：左侧一级，内容顶部二级。

## 10. 弹窗、抽屉和确认框

遮罩：

```text
普通弹窗：rgba(15, 23, 42, 0.4)
重要确认：rgba(2, 6, 23, 0.6)
```

遮罩关闭交互：

```text
关闭遮罩只能由一次完整的遮罩点击触发：同一个指针必须在遮罩区域内按下，并在遮罩区域内松开。
鼠标或触控在弹窗/抽屉内容区域按下，随后移动到遮罩区域再松开，不得关闭浮层。
不得仅凭 mouseup/pointerup 或 click/click.self 关闭；浏览器可能将内容区按下、遮罩区松开合成为遮罩祖先上的 click。
统一使用公共 v-backdrop-dismiss 指令：记录 pointerdown 的遮罩和指针，校验 pointerup 仍来自同一指针、实际松开位置仍在同一遮罩，再于 click 阶段关闭；取消、失焦、页面隐藏必须清理按下状态。
弹窗/抽屉内容区域必须阻止点击事件冒泡到遮罩；关闭按钮、取消按钮等显式操作仍按各自按钮事件处理。
键盘 Escape、系统返回键等非点击关闭方式必须由当前浮层明确支持，不能与遮罩松开事件混用。
```

自制 Vue 遮罩统一写法：

```vue
<script setup>
import { backdropDismiss as vBackdropDismiss } from "@platform-ui/backdrop-dismiss.js";
</script>

<template>
  <div v-if="open" class="dialog-mask" v-backdrop-dismiss="requestClose">
    <section role="dialog" aria-modal="true" @click.stop>
      <!-- 弹窗内容，保留显式关闭按钮和原有未保存保护 -->
    </section>
  </div>
</template>
```

指令必须绑定在实际遮罩节点上。内联赋值或带参数调用必须封装为函数，例如 `v-backdrop-dismiss="() => { open = false }"`，不要同时绑定直接关闭的 `@click`。按钮遮罩保留 `type="button"` 和可访问名称，公共指令支持其键盘激活。

第三方组件继续使用其完整点击校验，并通过浏览器回归验证；不能只看 `close-on-click-modal` 属性。小程序使用触摸处理器记录同一触点，校验松开位置不在内容面板内，在完整 `tap` 后关闭，触摸取消或页面隐藏时清理状态。原本不允许遮罩关闭的窗口不强制增加关闭行为。

变更后的必跑检查：`node scripts/check-backdrop-dismiss.cjs`；基础浏览器回归：`node --test packages/platform-ui/tests/backdrop-dismiss.browser.test.mjs`；CRM 桌面和手机回归：`node --test apps/crm/frontend/tests/backdrop.browser.test.mjs`；其他系统桌面代表遮罩回归：`node --test scripts/test-app-backdrop-dismiss.browser.mjs`；商城第三方及实际业务遮罩回归：`node apps/maijie-mall/frontend/scripts/backdrop-browser-test.mjs`。浏览器验证至少覆盖内容按下后移出、遮罩按下后移入、完整遮罩点击、取消/失焦，以及现有禁用关闭和未保存保护。默认仅 CRM 做手机端验证，其他系统按桌面端验证。

弹窗：

```text
圆角：10px-12px
背景：白色
头部：标题 + 副标题 + 关闭按钮
底部：右侧操作按钮，取消在左/前，确认在右/后
```

抽屉：

```text
从右侧进入
所有右侧抽屉必须使用统一右侧滑入动画，不允许直接瞬间出现
所有新老抽屉面板本体都必须挂统一动画类；后续启用旧模板或复制抽屉时也不能遗漏
新模板统一使用共享详情抽屉的 220ms，缓动 cubic-bezier(0.16, 1, 0.3, 1)，并尊重减少动态效果偏好
初始 transform: translateX(100%)，结束 transform: translateX(0)
动画只作用于抽屉面板本体，遮罩可淡入或直接显示，但不能影响抽屉滑入
宽度按业务复杂度，常规 420px-720px
内部必须有固定头部和底部操作区
长内容只滚动 body，不滚动整个页面
```

确认类操作：

```text
删除、停用、退出代理、放弃未保存修改必须二次确认
确认按钮使用语义色
文案直接说明后果，不写长段说明
```

未保存离开保护：

```text
所有存在编辑、勾选、排序、录入、权限配置、组织配置等可修改状态的页面，必须维护 dirty/未保存状态。
当 dirty 状态为 true 时，用户切换左侧导航、切换顶部/内容 tabs、返回上一级、关闭编辑面板或通过应用内入口离开当前编辑页，必须先弹窗确认。
确认框标题统一使用：是否放弃修改。
确认框按钮统一使用：继续编辑、确认放弃。
“继续编辑”使用蓝底白字主按钮，“确认放弃”使用红底白字危险按钮。
点击“继续编辑”：只关闭确认框，保留当前页面和未保存内容。
点击“确认放弃”：放弃当前未保存内容，并继续执行刚才的切换、关闭或返回动作。
保存成功、重新加载成功、放弃离开完成后，必须清空 dirty 状态。
不要使用浏览器原生 confirm；必须使用系统内统一样式弹窗。
```

浮层/下拉选择器：

```text
所有附着在按钮、输入框、表头筛选、人员/部门选择器上的小窗口，统一称为浮层或下拉选择器。
浮层打开后，点击对应触发器和浮层内容以外的其他区域，必须自动关闭。
浮层内点击、输入、勾选、滚动不能误触发外部关闭。
浮层分两种模式：
1. 普通选择模式：打开后直接显示可选项。
2. 搜索选择模式：打开后必须自动聚焦搜索输入框，让光标直接进入输入态；如果已有搜索词，优先选中或保留可继续输入。
搜索选择模式必须支持键盘输入，Enter 选择当前第一项或高亮项，Escape 关闭浮层。
```

## 11. 移动端规范

移动端不显示桌面左侧栏。

移动端顶部：

```text
高度：约 46px + safe-area
左侧：一级模块入口或返回
中间：当前页面标题
右侧：头像菜单
背景：白色或 #fbfdff
底部边框：#e2e8f0
```

移动菜单：

```text
一级页面选择使用顶部下拉面板
二级页面选择使用第二层面板
面板从顶部展开，不做底部 tab bar
遮罩使用深色半透明
```

移动端内容：

```text
优先卡片列表、分组表单、横向滚动表格
按钮高度不低于 40px
点击目标不小于 36px
文本必须 truncate 或换行，不能互相覆盖
```

## 15. 新页面开发检查清单

提交前逐项检查：

```text

```
